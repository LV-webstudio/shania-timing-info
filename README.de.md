# Shania Timing

> Ein schlankes, schreibgeschütztes Dashboard, das zeigt, was jede KI-Programmiersitzung tut und wie viel Zeit noch bleibt.

## Was es ist

Shania Timing sammelt von jeder KI-Programmiersitzung, die an einem Projekt arbeitet, einen „Herzschlag“ (Zustand, Aufgabentitel, Fortschritt) und zeigt ihn in einem kleinen, immer sichtbaren Desktop-Fenster sowie in einem Sitzungs-Dashboard. Es wird im Studio genutzt und ist auf Anfrage für Teams erhältlich, die mit mehreren KI-Sitzungen arbeiten. Es zeigt nur Informationen an und hat keine Schaltflächen, die auf die Sitzungen einwirken.

## Für wen

- Wer mehrere KI-Programmiersitzungen oder Rechner gleichzeitig betreibt und ständig fragt: „Wie lange noch?“
- Auf Anfrage erhältlich für Teams, die mit mehreren KI-Sitzungen arbeiten.

## Was es kann

- Herzschlag pro Sitzung mit eindeutigen Zuständen: läuft, wartet auf die Inhaberin, wartet auf den Zug, wartet auf eine Ressource, abgebrochen, erledigt.
- Eine Sitzung ohne aktuellen Herzschlag erscheint als „keine Daten“, nie als „läuft“.
- Restzeitschätzung aus gemessenen Durchschnittswerten je Aufgabentyp und Rechner statt aus Vermutungen; Wartezeiten in der Warteschlange werden getrennt ausgewiesen.
- Kleines rahmenloses Desktop-Fenster (Windows, Tauri), das im Vordergrund bleibt; im Test des Teams rund 28 MB RAM.
- Dashboard-Seite mit einer Karte pro Sitzung, animiertem Diagramm des KI-Nutzungskontingents, Tageszeitleiste, Deployments und Commits je Repository. Nur lesend.
- Datenschutzfilter: E-Mail-Adressen, spanische Telefonnummern und Steuer-/Ausweisnummern werden vor dem Schreiben geschwärzt; Commit-Autoren werden nicht kopiert.
